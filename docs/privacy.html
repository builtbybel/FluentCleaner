Privacy

FluentCleaner, Modern and Classic edition

FluentCleaner collects nothing. No telemetry, no analytics, no account, no ads. It runs on your PC and stays there.

What stays on your PC

Scan results, your selection, exclusions, custom cleaners and settings are stored only on your device: next to the app in the ZIP version, in the app's own data folder in the Microsoft Store version. Nothing of it is uploaded anywhere. Uninstalling the app removes it.

When the app goes online

Only when you click something. Nothing runs in the background.

  • Database update: downloads Winapp2.ini or Winapp3.ini from GitHub. Nothing is sent except the normal download request.
  • Check for updates: opens this website in your browser with the edition and version number in the address, so the page can tell you whether a newer one exists.
  • FluentSeed: opens a page that shows a shared selection. The selection sits after the # in the address, which browsers never send to the server.
  • Links to GitHub, PayPal or Ko-fi simply open in your browser.

Downloads and this website are hosted by GitHub, which may log your IP address as described in the GitHub Privacy Statement.

Optional AI explanations

Off by default. They only work if you enter your own API key for OpenAI, Anthropic or Groq. When you then ask for an explanation or a generated cleaner, the app sends that one request directly to the provider you picked: the cleaner rule's name, its warning, its path patterns and registry keys from the database, or the description you typed. No files, no file contents, no personal data. Your key is stored only on your device and is sent only to that provider. What the provider does with the request is covered by its own privacy policy.

Microsoft Store

If you install FluentCleaner from the Microsoft Store, the download and installation are handled by Microsoft under the Microsoft Privacy Statement. FluentCleaner itself receives none of that data.

Children

FluentCleaner collects no data from anyone, children included.

Changes and contact

If this ever changes, this page changes first. Questions: GitHub Issues.
